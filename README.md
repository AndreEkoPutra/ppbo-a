# 📚 Praktikum Pemrograman Berorientasi Objek

> Repository dokumentasi materi, contoh kode, latihan, dan hasil praktikum  
> Mata Kuliah **Praktikum Pemrograman Berorientasi Objek (PBO)**

---

## 👋 Tentang Repository

Repository ini digunakan untuk menyimpan dan mendokumentasikan seluruh hasil pengajaran selama menjalankan tugas sebagai **Asisten Laboratorium (Aslab)** pada mata kuliah **Praktikum Pemrograman Berorientasi Objek**.

Repository ini dikelola dan dikembangkan bersama **Dani Ali**.  
Seluruh materi, contoh implementasi, latihan, serta hasil praktikum akan dikembangkan dan disimpan secara bertahap melalui **Git & GitHub**.

---
